## Flagship projects
### [Fronko](https://github.com/faiz-gh/fronko)
An open-source, self-hostable digital business card platform for teams, live at [fronko.com](https://fronko.com). Cards open from an NFC tap or QR scan with no app needed, and leads flow back to the team through CRM and automation integrations. Built full stack with a **Go** API and a **Svelte 5 / SvelteKit** frontend on **PostgreSQL**, with SAML SSO, SCIM provisioning, S3-compatible storage and a two-container **Docker** deployment.

### [project-hydra](https://github.com/faiz-gh/project-hydra)
An applied cloud computing research testbed comparing **CockroachDB** with **PostgreSQL/Patroni** on the same five-node, three-cloud deployment (**GCP, Linode, Azure**). **Terraform** provisions the VM clusters; a Python measurement harness then records steady-state throughput and latency and injects faults to measure recovery time (RTO) and lost writes (RPO).
