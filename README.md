## 🚀 What I've been building

### [Fronko](https://github.com/faiz-gh/fronko) · [fronko.com](https://fronko.com)
An open-source, self-hostable digital business card platform for teams. Cards open from an NFC tap or QR scan with no app needed, and leads flow back to the team through CRM and automation integrations. Built with a **Go** API and a **Svelte 5 / SvelteKit** frontend on **PostgreSQL**, with analytics, SAML SSO, SCIM provisioning, S3-compatible storage and a two-container **Docker** deployment.

### [Project Hydra](https://github.com/faiz-gh/project-hydra)
An applied cloud computing research testbed comparing **CockroachDB** with **PostgreSQL/Patroni** on the same five-node, three-cloud deployment (**GCP, Linode, Azure**). **Terraform** provisions the VM clusters; a Python measurement harness then records steady-state throughput and latency and injects faults to measure recovery time (RTO) and lost writes (RPO).

### [Pairpad](https://github.com/faiz-gh/pairpad) · [try it live](https://pairpad.site)
A collaborative code pad with no signup and no modals: paste a link and you're in. Edits merge conflict-free with **Yjs CRDTs**, relayed over **WebSockets** by a **Go** server and rendered by a **Svelte 5** + CodeMirror 6 frontend. Rooms persist in **PostgreSQL**, with batched writes keeping the database off the hot path of every keystroke. It runs on an ARM instance on Oracle Cloud, deployed with Docker Compose and Traefik.
